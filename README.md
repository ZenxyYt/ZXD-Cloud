# Funkin' After Hours — FNF fan hub

A static GitHub Pages fan hub with an original browser rhythm-game mode, fan character guide, music links, and a local mod filename shelf.

## Included
- Responsive home page and navigation
- Original playable rhythm mode with generated demo charts, score, combo, health, pause, results, and difficulty options
- Fan character guide using original CSS placeholders (no official character art)
- Community modding/resource links
- Local mod shelf: records selected archive filenames in this browser only; it does not upload or run archives
- Official game, source-code, and soundtrack links

## Publish on GitHub Pages
1. Download and unzip this project.
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the root of your GitHub repository, replacing the old site files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment to finish.

## Important notes
- This is an unofficial fan project, not the official Friday Night Funkin' game.
- The playable mode is an original rhythm-game sample with generated practice charts; it does not contain official FNF songs, charts, art, characters, or game code.
- The official FNF source code is licensed under Apache 2.0, but the official assets are separately licensed and are not automatically covered by that code license. Check the current licenses and creator permissions before reusing or redistributing anything.
- The mod shelf only stores filenames in local browser storage. GitHub Pages is static hosting: it has no user accounts, shared uploads, server-side mod installation, or secure database. Do not upload mods unless you have permission to distribute them.
- The official game and creator resources are linked externally rather than copied into this project.
